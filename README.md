# Wicklow woodland screen (map)

A single self-contained Leaflet map (`index.html`) published with GitHub Pages
for embedding. It is generated by a separate private project; this repository
holds only the rendered map.

A desk screen, not a site assessment: verify on the ground and with the
Forestry Service before any application.

## Data

- Tailte Éireann: county boundaries, National Land Cover Map 2018, townlands
- NPWS: SAC, SPA, NHA/pNHA, native and ancient woodland
- EPA / Teagasc: soils, WFD waterbodies, pearl mussel areas
- National Monuments Service: Sites and Monuments Record
- Department of Agriculture, Food and the Marine: Private Forest Estate 2023,
  Forestry Licence Viewer extracts, anonymised LPIS parcels 2025 (CC BY 4.0)
- Irish Peat Soils Map 2024, Gilet et al. (CC BY 4.0)
- Copernicus DEM GLO-30; Hansen / UMD Global Forest Change
- Coillte forest inventory
- Land listings: summaries of public listings on MyHome.ie, Daft.ie, agent
  websites and Paul Lafferty Forest Sales; follow the source link on each
  listing for the agent's own details
- Basemaps: Esri, © OpenStreetMap contributors
